    How to Write Custom Algorithms

    This guide will walk you through the process of writing a custom algorithm for this platform.

    Generator Functions

    The most important thing to understand is that your algorithm must be a generator function. A generator function is a special type of function that can be paused and resumed, allowing us to visualize the state of the algorithm at each step.

    A generator function is defined using the `function*` syntax. Inside the function, you can use the `yield` keyword to pause the execution of the function and return a value. When the function is resumed, it will continue from where it left off.

    Example: Palindrome Checker

    Here is an example of a palindrome checker written as a generator function:

    function* isPalindrome(str) {
  const len = str.length;
  for (let i = 0; i < len / 2; i++) {
    // Highlight the characters being compared
    states[i] = 0;
    states[len - 1 - i] = 0;
    yield;

    if (str[i] !== str[len - 1 - i]) {
      // Not a palindrome, highlight the mismatched characters in red
      states[i] = 1;
      states[len - 1 - i] = 1;
      yield;
      return false;
    }

    // Characters match, highlight them in green
    states[i] = 2;
    states[len - 1 - i] = 2;
    yield;
  }

  return true;
}

    States

    The `states` array is used to keep track of the state of each element in the array or string being visualized. The following states are available:

    • `0`: Comparing (blue)
    • `1`: Swapping/Mismatch (red)
    • `2`: Sorted/Match (green)
    • `3`: Pivot/Special (purple)

    By updating the `states` array and using the `yield` keyword, you can create a step-by-step visualization of your algorithm.
