AlgoVision – Complexity Visualized

An interactive platform for visualizing algorithms.

Authors: Saran & Atharv

The Challenge: Understanding Abstract Algorithms

  • Learners often struggle to grasp abstract concepts in algorithms like sorting, searching, and their associated complexities.
  • Textbook diagrams and static code examples can be insufficient for deep understanding.
  • It's hard to see the step-by-step execution of an algorithm and how the data structure changes over time.

Our Solution: AlgoVision

  • An interactive web-based tool that brings algorithms to life through animation.
  • Provides a visual representation of algorithm execution, making complex operations tangible.
  • Allows for real-time experimentation and comparison of different algorithms.

Key Features (v1.1)

Algorithm Visualization

Sorting: Bubble, Selection, Insertion, Shell, Merge, Quick.
Searching: Linear, Binary.

Multiple Views

Visualize data as dynamically sized bars or as a classic array of numbers.

Code Display

View the implementation of each algorithm in multiple languages (JavaScript, Python, C++, Java).

Complexity & Playback

Displays time/space complexity. Play, pause, reset the animation, and control its speed.

How it Works: The Animation Engine

We use JavaScript generator functions to create iterative animations. The yield keyword pauses the algorithm's execution at each step, allowing the visualization to be redrawn. This creates a step-by-step animation of the algorithm.

function* bubbleSort(arr, states) {
    for (let i = 0; i < arr.length; i++) {
        for (let j = 0; j < arr.length - i - 1; j++) {
            states[j] = 0; states[j + 1] = 0; // State: Comparing
            yield; // Pause for visualization
            if (arr[j] > arr[j + 1]) {
                states[j] = 1; states[j + 1] = 1; // State: Swapping
                yield; // Pause for visualization
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; // Swap
                yield; // Pause for visualization
            }
            states[j] = -1; states[j + 1] = -1; // Reset state
        }
        states[arr.length - 1 - i] = 2; // State: Sorted
    }
}
